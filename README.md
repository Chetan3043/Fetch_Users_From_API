# 🌐 Fetch and Display Data from a Public API (Using Fetch API)

A modern and responsive web project that fetches user data from a **public API** and displays it beautifully on a webpage using **HTML, CSS, and JavaScript**. It also includes **network error handling** and a **reload button** to refetch data when the internet is reconnected.

---

## 🎯 Objective
To build a webpage that:
- Fetches and displays user data dynamically using the Fetch API  
- Handles network and API errors gracefully  
- Allows users to manually reload data  

---

## 🧰 Tools Used
- **HTML5** – Webpage structure  
- **CSS3** – Styling and responsive layout  
- **JavaScript (Fetch API)** – Fetching and displaying API data  
- **VS Code** – Code editor  
- **Chrome Browser** – Testing and debugging  

---

## 🧩 Features
✅ Fetches user data from a free public API  
✅ Displays **name, email, and address** for each user  
✅ Stylish and responsive **card-based layout**  
✅ Shows a **red warning message** if the internet is off  
✅ **Reload button** to refetch data after reconnection  
✅ Automatically detects online/offline status  
✅ Clean and modern UI with hover effects  

---

## 🔗 API Source
Data is fetched from:  
👉 [https://jsonplaceholder.typicode.com/users](https://jsonplaceholder.typicode.com/users)

## 🧑‍💻 How It Works
1. The page loads and automatically fetches user data from the API.  
2. Each user’s **name, email, and address** are displayed in styled cards.  
3. If the internet is off, it shows a custom **“You are offline”** message.  
4. When you reconnect, it auto-fetches the data again.  
5. You can also press the **Reload button** to fetch data manually.

---

## 🚀 How to Run
1. Open the project folder in **VS Code**.  
2. Open `index.html` → Right-click → **“Open with Live Server”**.  
3. View results in Chrome browser.  
4. Try disabling internet to test error handling.  
5. Reconnect and click **Reload Data** to refetch.
